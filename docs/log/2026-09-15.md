## Velo_bot (48 коммитов, 23 задачи команды, ≈$24 по счётчику API — в подписку)
- **Пользовательские истории раздела «Маршруты»** — docs/user_stories_routes.md, 23 истории с критериями приёмки.
- **Миссия «Карточка маршрута»** — трек становится личным выездом со статистикой (км, время в движении, средняя скорость, набор высоты), зачёт сразу; публикация в базу по кнопке «➕ Добавить в базу маршрутов» с мастером названия/описания/типа/сложности; автор редактирует маршрут из карточки; «проехал» у чужого маршрута спрашивает время и считает темп.
- **Миссия «Неделя в цифрах»** — недельный лидерборд с данными и сравнением с прошлой неделей, итоги недели по воскресеньям в 21:00 с отпиской, архив недель, GPX в ручном «проехал»; полировка текстов (целые км, склонения, без нулей).
- **Миссия «Поиск и общение»** — кнопка «Добавить маршрут», фильтры по длине/типу/оценке, защита от дублей, комментарии, уведомления о новых маршрутах в округе, «Рядом со мной» по геопозиции.
- **Миссия «Автономный запуск»** — Dockerfile, docker-compose с томом data/, heartbeat, scripts/deploy.sh, server_setup.md, перенос данных на сервер и бэкап обратно.
- Устойчивость к обрывам сети (повтор отправки) — влито утром.
- Логотипы канала: 6 вариантов в палитре бота + 3 с гравелом (assets/logo/).
